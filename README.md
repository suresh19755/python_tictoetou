# 🎮 Tic Tac Toe (Python & Pygame)

A classic, fully functional **Tic Tac Toe** game built using Python and the Pygame library. This project demonstrates game logic implementation, GUI rendering, and handling user input in real-time.

## ✨ Key Features

* **Graphical User Interface:** No console text! A clean, colorful grid window.
* **2-Player Local Mode:** Play against a friend on the same computer.
* **Win Animation:** Draws a line across the winning row, column, or diagonal.
* **Restart Functionality:** Dedicated "Start" and "End Game" buttons to reset the board without closing the app.
* **Executable Version:** converted to `.exe` so it can run on computers without Python installed.

## 🛠️ Technologies Used

* **Language:** Python 3.x
* **Library:** Pygame
* **Build Tool:** PyInstaller (for creating the executable)

## 🚀 How to Run

### Option 1: Run the Executable (No Python Required)
1.  Download the `dist/game.exe` file from this repository.
2.  Double-click to play!

### Option 2: Run from Source Code
1.  Clone this repository.
2.  Install Pygame:
    ```bash
    pip install pygame
    ```
3.  Run the game script:
    ```bash
    python game.py
    ```

## 🕹️ How to Play

1.  Click **START** to begin a new game.
2.  Player 1 is **X**, Player 2 is **O**.
3.  Click on any empty grid square to place your mark.
4.  The first player to get 3 in a row (horizontally, vertically, or diagonally) wins!
5.  The game will draw a line over the winning combination.
6.  Click **END GAME** or **START** to reset.
